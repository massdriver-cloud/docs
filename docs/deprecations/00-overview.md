Massdriver removes deprecated features on their end-of-life date. After that date, the feature stops working. Migrate before the end-of-life date.

| Feature | End of life | Replacement |
|---|---|---|
| [Service account secrets](/deprecations/service-account-secrets) | December 31, 2026 | Access tokens |
| [Connections and artifacts aliases](/deprecations/connections-and-artifacts-aliases) | December 31, 2026 | `dependencies`, `resources`, and `id` |
| [Legacy bundle format](/deprecations/legacy-bundle-format) | December 31, 2026 | `dependencies` and `resources` blocks |
| [Raw JSON schema resource types](/deprecations/raw-json-schema-resource-types) | December 31, 2026 | `massdriver.yaml` resource types |
| [Renamed resource type names](/deprecations/renamed-resource-type-names) | December 31, 2026 | The new resource type name |
| [Artifact REST paths](/deprecations/artifact-rest-paths) | December 31, 2026 | `/v1/resources` and `/v1/resource-types` |
| [GraphQL V2 fields](/deprecations/graphql-v2-fields) | December 31, 2026 | Replacement fields and operations |
