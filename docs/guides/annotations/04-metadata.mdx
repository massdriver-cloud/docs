# Metadata

Stash entries that have a label show as metadata in the Massdriver UI. Everyone who can view the project sees metadata. Metadata needs no setup. Add a label when you write the entry:

```bash
mass stash set billing-dev-app.schema.version "42" --label "Schema version"
```

## Where metadata shows

| Place | Entries |
|---|---|
| The **Metadata** tab of an instance | Labeled entries on the instance |
| The **Deployment metadata** section of a deployment's details | Labeled entries on the deployment, written by the deployment's steps |
| The **Metadata** card on the project overview | Labeled entries on the project |

## What it looks like

| Entry | Looks like | Meaning |
|---|---|---|
| A TEXT entry | <MetadataTextRow label="A metadata row with the label Schema version, the key schema.version, and the value 42" /> | The label, the key, and the value. |
| A JSON entry | <MetadataJsonRow label="A metadata row for stats/traffic with one tile for each top-level field: rps 240, errors_5m 2, p95_ms 85" /> | One tile for each top-level field. A nested object shows as JSON text in its tile. |
| An entry with flags | <MetadataPillsRow label="A metadata row with a masked value and three pills: expires in 2 hours, immutable, and sensitive" /> | Pills show when the entry expires, when it is immutable, and when it is sensitive. A sensitive value is masked unless you can change the stash. |
| Unlabeled entries | <MetadataFooter label="Footer text: 3 entries have no label, with the command mass stash list billing-dev-app" /> | Entries without a label do not show as rows. The Metadata tab counts them and gives the command that lists them. |

The project card shows the label, the value, and the expiry pill for each entry.

Keys that start with `md/` do not show as rows in any of these places, and the Metadata tab does not count them as unlabeled entries. [Widgets](/guides/annotations/widgets) read them instead.

## Widgets on the Metadata tab

The instance Metadata tab shows a **Widgets** row above the entries. It shows the instance's automatic widgets:

- The `md/health` dot, with its value.
- The `md/usage` bar, with the value and the limit.
- The `md/traffic` label for the traffic that leaves the instance. Its color follows the traffic state, and it says "stale" when the data is more than 10 minutes old.

<MetadataWidgetsRow label="Widgets row: an amber dot with the value degraded, a usage bar at 86 of 100, and a teal traffic label that says 240 rps" />

The row shows only the widgets that have a valid value. It does not show when the instance has none. When you hide automatic widgets with the **Widgets** button on the canvas, the row is hidden too.
