Filter criteria for narrowing which members of an organization are returned.


```graphql
input OrganizationMembersFilter {
  search: String
}
```




### Fields

#### [<code style={{ fontWeight: 'normal' }}>OrganizationMembersFilter.<b>search</b></code>](#search)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String</b></code>](/api/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#search\} 
Case-insensitive search for part of a member's `email`, `firstName`, or `lastName`.
So `search: "lee"` matches `lee@example.com`, a member named Leela, and a member
with the last name Lee. Blank or whitespace-only values skip this filter.
