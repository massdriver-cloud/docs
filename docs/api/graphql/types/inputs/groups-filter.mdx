Filter criteria for narrowing which groups are returned.

All filters combine with AND logic. A group must match every filter you set to appear
in the results. Omit a filter to not restrict on that field.


```graphql
input GroupsFilter {
  search: String
  accountId: IdFilter
  serviceAccountId: IdFilter
}
```




### Fields

#### [<code style={{ fontWeight: 'normal' }}>GroupsFilter.<b>search</b></code>](#search)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String</b></code>](/api/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#search\} 
Case-insensitive search across the group's `name` and `description`. Matches a prefix
of the name or whole words in either field.

Blank or whitespace-only values skip this filter. When `search` is active and no
explicit `sort` is provided, results are ranked by relevance.
