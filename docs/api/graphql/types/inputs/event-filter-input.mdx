Selects audit log events. An event matches when it matches every field. An empty field matches every event,
so an empty filter matches all of the organization's events.

```graphql
{
  types: ["deployment.*", "instance.alarm_triggered"]
  attributes: "{\"md-environment\": \"prod\"}"
  actorTypes: [ACCOUNT, SERVICE_ACCOUNT]
}
```


```graphql
input EventFilterInput {
  types: [String!]
  metadata: Map
  attributes: Map
  actorTypes: [AuditLogActorType!]
}
```
