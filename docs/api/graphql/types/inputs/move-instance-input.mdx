Move an instance, with its configuration, state, and deployment history, to an environment in another project.


```graphql
input MoveInstanceInput {

}
```




### Fields

#### [<code style={{ fontWeight: 'normal' }}>MoveInstanceInput.<b>preserveHistory</b></code>](#preserve-history)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Boolean!</b></code>](/api/graphql/types/scalars/boolean.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#preserve-history\} 
When the move replaces a DECOMMISSIONED instance, true moves that instance's deployments, alarms, and costs onto the moved instance. An alarm for a cloud resource that the moved instance already has an alarm for is deleted. Costs for a billing period that both instances have are added together. False deletes them with the replaced instance.
