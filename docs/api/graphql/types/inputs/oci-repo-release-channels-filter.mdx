#### [<code style={{ fontWeight: 'normal' }}>OciRepoReleaseChannelsFilter.<b>channel</b></code>](#channel)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>OciRepoChannel</b></code>](/api/graphql/types/enums/oci-repo-channel.mdx) <Badge class="badge badge--secondary " text="enum"/> \{#channel\} 
Return only stable channels (`STABLE`: `latest`, `~1`, `~1.2`) or only development channels (`DEV`: `latest+dev`, `~1+dev`, `~1.2+dev`). Omit to return both. A development channel is listed even when it currently resolves to the same version as its stable counterpart, because the two track future releases differently.
