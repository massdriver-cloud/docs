Claims the CI run's ID token must carry, with exact string values. GitHub rules must include `repository_owner_id`; GitLab rules must include `namespace_id`. Add `repository_id` or `project_id` to limit the rule to one repository, and `ref` to limit it to one branch.


#### [<code style={{ fontWeight: 'normal' }}>CreateTrustRuleInput.<b>issuer</b></code>](#issuer)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String!</b></code>](/api/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#issuer\} 
The OIDC issuer URL of the CI platform, such as `https://token.actions.githubusercontent.com` for GitHub Actions or `https://gitlab.com` for GitLab CI. Must be one of the issuers this Massdriver server trusts.


#### [<code style={{ fontWeight: 'normal' }}>CreateTrustRuleInput.<b>name</b></code>](#name)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String!</b></code>](/api/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#name\} 
A label for this rule. Access tokens issued through the rule carry this name.
