Alpha: this API can change or be removed at any time, without notice.

Set the value of a key in a stash. Setting a key that has a value replaces the value and every other setting of the entry.


```graphql
input AlphaSetStashEntryInput {
  format: AlphaStashFormat
  immutable: Boolean
  label: String
  sensitive: Boolean
  ttl: Int
  value: String!
}
```

When true, the key cannot be set again until the entry expires or is deleted. Setting an immutable entry fails if the key already has a value.


#### [<code style={{ fontWeight: 'normal' }}>AlphaSetStashEntryInput.<b>label</b></code>](#label)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String</b></code>](/api/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#label\} 
A human-readable name for the entry, shown in the Massdriver UI. Up to 255 characters. An empty label is the same as no label. The label is not encrypted and is shown even when the entry is sensitive, so do not put secrets in it.


#### [<code style={{ fontWeight: 'normal' }}>AlphaSetStashEntryInput.<b>sensitive</b></code>](#sensitive)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Boolean</b></code>](/api/graphql/types/scalars/boolean.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#sensitive\} 
When true, the value is encrypted and is returned only to callers who can change the stash.


#### [<code style={{ fontWeight: 'normal' }}>AlphaSetStashEntryInput.<b>ttl</b></code>](#ttl)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Int</b></code>](/api/graphql/types/scalars/int.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#ttl\} 
Seconds until the entry expires. An expired entry is not returned and is deleted soon after. At most 315360000 (10 years). Leave empty to keep the entry until you delete it.


#### [<code style={{ fontWeight: 'normal' }}>AlphaSetStashEntryInput.<b>value</b></code>](#value)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String!</b></code>](/api/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#value\} 
The value to store. Massdriver returns it exactly as written. The size limit is 65536 bytes unless your installation sets another.
