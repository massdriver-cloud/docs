Alpha: this API can change or be removed at any time, without notice.

Pin a new annotation to a project, environment, component, instance, deployment, or link. Only you can see it.


```graphql
input AlphaCreateAnnotationInput {
  inputs: Map
  kind: AlphaAnnotationKind!
  surfaces: [String!]!
  template: String
}
```




### Fields

#### [<code style={{ fontWeight: 'normal' }}>AlphaCreateAnnotationInput.<b>inputs</b></code>](#inputs)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Map</b></code>](/api/graphql/types/scalars/map.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#inputs\} 
A JSON object that maps each input of the widget to a stash entry. Use the input names from `alphaWidgetCatalog`, and set every required input. Required for WIDGET annotations and empty for NOTE annotations. Each value has `source` (always `stash`), `scope` (one of `project`, `environment`, `component`, `instance`, or `deployment`, set to an ID in the annotation's project), `key`, and an optional `path` (a list of keys into a JSON entry's data).


#### [<code style={{ fontWeight: 'normal' }}>AlphaCreateAnnotationInput.<b>kind</b></code>](#kind)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>AlphaAnnotationKind!</b></code>](/api/graphql/types/enums/alpha-annotation-kind.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="enum"/> \{#kind\} 
NOTE shows a Liquid template that the Massdriver UI renders. WIDGET shows one widget from `alphaWidgetCatalog` and connects its inputs to stash entries. The kind cannot be changed later.


#### [<code style={{ fontWeight: 'normal' }}>AlphaCreateAnnotationInput.<b>surfaces</b></code>](#surfaces)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>[String!]!</b></code>](/api/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#surfaces\} 
Where the Massdriver UI shows the annotation, from 1 to 8 surfaces. Each one is lowercase words joined by dots, up to 64 characters, and starts with the kind of entity the annotation is on, such as `instance.canvas_node`. An annotation on a component can also use `instance` surfaces. A WIDGET annotation has exactly one surface: the name of a widget, such as `instance.usage_bar`.


#### [<code style={{ fontWeight: 'normal' }}>AlphaCreateAnnotationInput.<b>template</b></code>](#template)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String</b></code>](/api/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#template\} 
The Liquid template to show, up to 4096 bytes. Required for NOTE annotations and empty for WIDGET annotations. Massdriver stores it as written and does not evaluate it.
