How many resources a bundle dependency takes.


```graphql
enum BundleDependencyCardinality {
  ONE
  MANY
}
```




### Values

#### [<code style={{ fontWeight: 'normal' }}>BundleDependencyCardinality.<b>ONE</b></code>](#one) \{#one\} 
The dependency takes exactly one resource.


#### [<code style={{ fontWeight: 'normal' }}>BundleDependencyCardinality.<b>MANY</b></code>](#many) \{#many\} 
The dependency takes any number of resources of its type. The IaC receives a map from resource ID to resource.
