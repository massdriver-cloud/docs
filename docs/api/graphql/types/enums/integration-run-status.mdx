The outcome of one scheduled run of an integration.


```graphql
enum IntegrationRunStatus {
  SUCCEEDED
  FAILED
}
```




### Values

#### [<code style={{ fontWeight: 'normal' }}>IntegrationRunStatus.<b>SUCCEEDED</b></code>](#succeeded) \{#succeeded\} 
The run finished and its data was saved.


#### [<code style={{ fontWeight: 'normal' }}>IntegrationRunStatus.<b>FAILED</b></code>](#failed) \{#failed\} 
The run stopped with an error. `message` holds the error.
