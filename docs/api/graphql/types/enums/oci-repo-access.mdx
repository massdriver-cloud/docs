How you can see an OCI repository.

You can see a repository when a group policy gives you `repo:view` on it, or
when the repository is granted to a project you can view. A grant adds the
repository to what you can see even when no `repo:view` policy matches it,
and a deny `repo:view` policy does not remove it.


```graphql
enum OciRepoAccess {
  GRANT
  POLICY
}
```




### Values

#### [<code style={{ fontWeight: 'normal' }}>OciRepoAccess.<b>GRANT</b></code>](#grant) \{#grant\} 
A grant on the repository matches the project. Components from this repository can be added to that project.


#### [<code style={{ fontWeight: 'normal' }}>OciRepoAccess.<b>POLICY</b></code>](#policy) \{#policy\} 
Only your `repo:view` group policies match the repository. No grant matches the project, so adding a component from this repository to the project is refused until the repository is granted to it.
