Which params a new instance gets from its source instance. Fields that the bundle's params
schema marks as not copyable are never copied.


```graphql
enum CopyParams {
  NONE
  CONFIGURED
  LATEST
}
```




### Values

#### [<code style={{ fontWeight: 'normal' }}>CopyParams.<b>NONE</b></code>](#none) \{#none\} 
Do not copy params. New instances start with empty params.


#### [<code style={{ fontWeight: 'normal' }}>CopyParams.<b>CONFIGURED</b></code>](#configured) \{#configured\} 
Copy the source instance's current `params`. These are saved when a deployment is created or a proposed deployment is approved.


#### [<code style={{ fontWeight: 'normal' }}>CopyParams.<b>LATEST</b></code>](#latest) \{#latest\} 
Copy the params of the source instance's newest deployment, including plans and proposed deployments. Decommissions and rejected proposals are skipped. If the instance has no such deployment, its current `params` are copied.
