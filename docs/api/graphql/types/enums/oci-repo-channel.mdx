The release line a version or release channel belongs to.


```graphql
enum OciRepoChannel {
  STABLE
  DEV
}
```




### Values

#### [<code style={{ fontWeight: 'normal' }}>OciRepoChannel.<b>STABLE</b></code>](#stable) \{#stable\} 
Stable releases. For tags, versions with no pre-release suffix (e.g., `1.2.3`). For release channels, `latest`, `~1`, and `~1.2`.


#### [<code style={{ fontWeight: 'normal' }}>OciRepoChannel.<b>DEV</b></code>](#dev) \{#dev\} 
Development builds. For tags, pre-release versions (e.g., `1.2.4-dev.20260101T120000Z`). For release channels, `latest+dev`, `~1+dev`, and `~1.2+dev`.
