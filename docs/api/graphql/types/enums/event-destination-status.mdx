Whether a destination receives events.


```graphql
enum EventDestinationStatus {
  ACTIVE
  PAUSED
}
```




### Values

#### [<code style={{ fontWeight: 'normal' }}>EventDestinationStatus.<b>ACTIVE</b></code>](#active) \{#active\} 
The destination receives the events that match its filter.


#### [<code style={{ fontWeight: 'normal' }}>EventDestinationStatus.<b>PAUSED</b></code>](#paused) \{#paused\} 
The destination receives no events. Events that match its filter while it is paused are not sent. Massdriver pauses a destination when a send fails and no send has succeeded for 24 hours.
