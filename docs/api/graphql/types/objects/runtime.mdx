A bundle that applications run on.

A runtime holds the infrastructure-as-code, params, and the dependencies its
infrastructure needs. Its massdriver.yaml lists `runtime` under `provides`.
Applications build on one exact runtime version and add their own
dependencies, resources, environment variables, and secrets.


```graphql
type Runtime {
  id: ID!
  latest: Bundle!
  versions(
    cursor: Cursor
  ): BundlesPage!

    filter: ApplicationsFilter
    sort: ApplicationsSort
    cursor: Cursor
  ): ApplicationsPage!
  adoption: [RuntimeVersionAdoption!]!
}
```
