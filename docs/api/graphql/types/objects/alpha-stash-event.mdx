Alpha: this API can change or be removed at any time, without notice.

A stash entry was set or deleted. Events are keyed by `scope` and `key`. An entry that expires sends no
event, so drop an entry when its `expiresAt` passes.


```graphql
type AlphaStashEvent {
  action: AlphaStashEventAction!
  scope: AlphaStashScopeRef!
  key: String!
  entry: AlphaStashEntry
  timestamp: DateTime!
}
```
