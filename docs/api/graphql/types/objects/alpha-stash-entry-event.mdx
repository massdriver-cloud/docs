Alpha: this API can change or be removed at any time, without notice.

A stash entry was set or deleted, sent to `projectEvents`, `environmentEvents`, `instanceEvents`, and
`deploymentEvents` by the entity that holds the entry. The action is `UPDATED` when the entry is set and
`DELETED` when it is deleted. An entry that expires sends no event.

| Stash       | Subscriptions                                              |
|-------------|------------------------------------------------------------|
| Project     | `projectEvents`                                            |
| Environment | `projectEvents`, `environmentEvents`                       |
| Component   | `projectEvents`                                            |
| Instance    | `environmentEvents`, `instanceEvents`                      |
| Deployment  | `environmentEvents`, `instanceEvents`, `deploymentEvents`  |


```graphql
type AlphaStashEntryEvent implements Event {
  action: EventAction!
  timestamp: DateTime!
  scope: AlphaStashScopeRef!
  key: String!
  entry: AlphaStashEntry
}
```

### Interfaces

#### [<code style={{ fontWeight: 'normal' }}><b>Event</b></code>](/api/graphql/types/interfaces/event.mdx) <Badge class="badge badge--secondary " text="interface"/> 
Base interface implemented by all lifecycle events.

Every event carries an `action` describing what happened and a `timestamp` recording
when it occurred. Concrete event types add a field for the affected resource.

Because each subscription returns a union, use an `... on Event` fragment to
access the shared fields and concrete fragments for the resource payload:

```graphql
subscription {
  projectEvents(organizationId: "my-org", projectId: "my-project") {
    ... on Event { action timestamp }
    ... on ComponentEvent {
      component { id name }
    }
    ... on LinkEvent {
      link { id fromField toField }
    }
  }
}
```
