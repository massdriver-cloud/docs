A key and value stored on a project, environment, component, instance, or deployment. Massdriver stores the
value and returns it as written. It does not read the value or act on it.


```graphql
type StashEntry {
  key: String!
  label: String
  value: String
  data: Map
  format: StashFormat!
  immutable: Boolean!
  sensitive: Boolean!
  expiresAt: DateTime
  updatedAt: DateTime!
}
```
