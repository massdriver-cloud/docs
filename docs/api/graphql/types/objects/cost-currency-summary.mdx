Cloud-provider cost metrics in one currency.

Amounts in different currencies are never converted or added together. Each sample's
`currency` matches this entry's `currency`, or is null when that sample has no billing data.


```graphql
type CostCurrencySummary {
  currency: String!
  lastMonth: CostSample!
  monthlyAverage: CostSample!
  lastDay: CostSample!
  dailyAverage: CostSample!
}
```
