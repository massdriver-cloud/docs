How many applications and instances use one version of a runtime.

An application counts toward the runtime version that its newest version is
built on. An instance counts toward the runtime version that its
infrastructure runs: the runtime of the bundle from its latest completed
provision. The instance count for a version is the number of instances that
`instances(filter: { runtime: { eq: "name@version" } })` returns.


```graphql
type RuntimeVersionAdoption {
  version: Semver!
  applicationCount: Int!
  instanceCount: Int!
}
```
