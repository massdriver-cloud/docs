Definition of a secret expected by an instance's bundle, and whether a value has been set.

Bundles declare the secrets they consume in their `app.secrets` manifest. Each
field describes one expected secret. Secret values themselves are never returned by the API.


```graphql
type InstanceSecretField {
  name: String!
  required: Boolean!
  title: String
  description: String
  isSet: Boolean!
  sha256: String @deprecated
}
```
