A bundle that runs on a runtime.

An application adds its own dependencies, resources, environment variables,
and secrets to a runtime. Its massdriver.yaml sets `app.runtime`, and each
published version is built on one exact runtime version.


```graphql
type Application {
  id: ID!
  latest: Bundle!
  runtime: Runtime
  runtimeAccessGroups(
    sort: GroupsSort
    cursor: Cursor
  ): GroupsPage!
  versions(
    cursor: Cursor
  ): BundlesPage!
  instances(
    filter: InstancesFilter
    sort: InstancesSort
    cursor: Cursor
  ): InstancesPage!
}
```
