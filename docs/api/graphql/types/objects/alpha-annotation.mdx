Alpha: this API can change or be removed at any time, without notice.

Your own note, pinned to a project, environment, component, instance, deployment, or link, and shown on one
or more surfaces of the Massdriver UI. Only you can see your annotations.


```graphql
type AlphaAnnotation {
  id: ID!
  kind: AlphaAnnotationKind!
  project: Project!
  entity: AlphaAnnotationEntity!
  surfaces: [String!]!
  template: String
  inputs: Map
  createdAt: DateTime!
  updatedAt: DateTime!
}
```
