A widget drawn from a well-known stash key.


```graphql
type AlphaWidget {
  name: String!
  scope: AlphaStashScopeRef!
  rolledUpTo: AlphaStashScopeRef
  segments: Map!
  values: Map!

  expiresAt: DateTime
}
```
