Metadata about an encrypted secret attached to an instance.

Secrets are encrypted key-value pairs injected at deploy time. Each organization's secrets are
encrypted with keys that belong only to that organization, and Massdriver replaces the keys every
week. The API never returns secret values -- only the name and timestamps are exposed.


```graphql
type InstanceSecret {
  name: String!
  sha256: String! @deprecated
  createdAt: DateTime!
  updatedAt: DateTime!
}
```
