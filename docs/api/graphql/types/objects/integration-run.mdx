One scheduled run of an integration.

Runs are kept for the install's retention, 90 days by default. The data a run collects, such as costs,
is kept separately and is not deleted with the run.


```graphql
type IntegrationRun {
  id: ID!
  status: IntegrationRunStatus!
  message: String
  startedAt: DateTime!
  finishedAt: DateTime!
}
```
