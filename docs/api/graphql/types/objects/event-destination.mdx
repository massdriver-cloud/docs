A place outside Massdriver that receives the organization's audit log events.

Massdriver sends each event that matches the `filter`, one at a time, and retries failed sends with
backoff. Order is not guaranteed. A receiver can drop duplicates by the event `id`.


```graphql
type EventDestination {
  id: ID!
  name: String!
  adapter: EventDestinationAdapter!
  config: Map!
  filter: EventFilter!
  condition: String
  status: EventDestinationStatus!
  signingSecret: String
  failingSince: DateTime
  createdAt: DateTime!
  updatedAt: DateTime!
  deliveries(
    filter: EventDeliveriesFilter
    sort: EventDeliveriesSort
    cursor: Cursor
  ): EventDeliveriesPage
}
```
