Alpha: this API can change or be removed at any time, without notice.

Subscribe to stash entries that are set or deleted in a project. You need `stash:view` on the project, and on
the environment when you pass `environmentId`.

Without `environmentId`, you get events for the project, its environments, and its components. With
`environmentId`, you also get events for that environment's instances and their deployments.

An event's `entry` is null when you do not have `stash:view` on the stash's entity. A sensitive entry's value
is always null in an event. An entry that expires sends no event.

```graphql
subscription {
  alphaStashEvents(organizationId: "my-org", projectId: "ecomm", environmentId: "ecomm-prod") {
    action
    scope { kind id }
    key
    entry { value expiresAt }
    timestamp
  }
}
```


```graphql
alphaStashEvents(
  organizationId: ID!
  projectId: ID!
  environmentId: ID
): AlphaStashEvent
```

A stash entry was set or deleted. Events are keyed by `scope` and `key`. An entry that expires sends no
event, so drop an entry when its `expiresAt` passes.
