Alpha: this API can change or be removed at any time, without notice.

Subscribe to the UI notices you can see in your organization, as Massdriver sets them. One subscription
covers every project and environment where you have `stash:view`, including the ones created after you
subscribe. You do not get a notice about a project or environment where you do not have `stash:view`.

A notice is an `md/v1/ui-ephemeral-notice` stash entry. Drop it when its `expiresAt` passes: an expiry sends
no event.

```graphql
subscription {
  alphaUiNotices(organizationId: "my-org") {
    scope { kind id }
    data
    expiresAt
  }
}
```


```graphql
alphaUiNotices(
  organizationId: ID!
): AlphaStashEntry
```
