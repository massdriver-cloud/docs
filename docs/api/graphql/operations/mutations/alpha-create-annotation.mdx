Alpha: this API can change or be removed at any time, without notice.

Pin a new annotation to a project, environment, component, instance, deployment, or link. Only you can see
it.

You need `project:view` on the project. Service accounts cannot have annotations. You can have up to 200
annotations in each project unless your installation sets another limit.

```graphql
mutation {
  alphaCreateAnnotation(
    organizationId: "my-org"
    projectId: "ecomm"
    entity: { instance: "ecomm-prod-database" }
    input: {
      kind: NOTE
      surfaces: ["instance.canvas_node"]
      template: "Schema version: {{ instance.stash[\"schema.version\"] }}"
    }
  ) {
    successful
    result { id kind surfaces }
    messages { field message }
  }
}
```
