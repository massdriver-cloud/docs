Let CI runs from a GitHub or GitLab repository act as a service account.

The issuer must be one this Massdriver server trusts. If rules on two different service
accounts match the same CI run, the run gets no token. Requires the
`organization:manageServiceAccounts` action.

**Example:**

```graphql
mutation {
  createTrustRule(
    organizationId: "my-org"
    serviceAccountId: "b2f0c1de-5a8e-4c43-9f3a-6f1d0e7a9b21"
    input: {
      name: "aws catalog"
      issuer: "https://token.actions.githubusercontent.com"
      claims: "{\"repository_owner_id\": \"4401\", \"repository_id\": \"811\", \"ref\": \"refs/heads/main\"}"
    }
  ) {
    result { id name }
    successful
    messages { field message }
  }
}
```
