Alpha: this API can change or be removed at any time, without notice.

Change the surfaces, template, or inputs of one of your annotations. Fields you leave out keep their
values. The kind and the entity cannot be changed.

You need `project:view` on the annotation's project.

```graphql
mutation {
  alphaUpdateAnnotation(
    organizationId: "my-org"
    id: "4f6e2a3c-8d1b-4c5e-9a7f-1b2c3d4e5f60"
    input: { surfaces: ["instance.canvas_node", "instance.card"] }
  ) {
    successful
    result { id surfaces }
    messages { field message }
  }
}
```
