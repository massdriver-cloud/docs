Change an integration's configuration.

The new `config` replaces the current one and must conform to the integration
type's `configSchema`. The change applies right away. Only some integration
types accept a new config; for the others, delete the integration and create
it again.

For SCIM, `seat_attribute` and `seat_value` set which users hold a seat. A
change gives or releases seats for every provisioned user.

```graphql
mutation {
  updateIntegration(
    organizationId: "my-org"
    id: "scim"
    input: {
      config: "{\"seat_attribute\": \"roles\", \"seat_value\": \"licensed\"}"
    }
  ) {
    result {
      id
      config
    }
    successful
    messages { field message }
  }
}
```




```graphql

  organizationId: ID!
```
