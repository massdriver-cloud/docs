Create a new project from an existing environment.

The new project gets the source project's blueprint, the same as `cloneProject`, and one
environment. Each instance in the new environment uses the bundle version and release
strategy of the matching source instance. Set `copyParams` to also copy the source
instances' params.

Secrets, remote references, and environment defaults are not copied. If any step fails,
nothing is created.

```graphql
mutation {
  createProjectFromEnvironment(
    organizationId: "acme"
    sourceEnvironmentId: "template-dev"
    input: {
      id: "payments"
      name: "Payments"
      environment: { id: "dev", name: "Development" }
      copyParams: LATEST
    }
  ) {
    successful
    result { id }
  }
}
```
