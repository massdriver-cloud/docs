Fetch a single runtime by name. Returns `null` with a `NOT_FOUND` error if
no runtime with that name exists or you cannot view its repository.

```graphql
query {
  runtime(organizationId: "your-org-id", id: "lambda") {
    latest { version createdAt }
    applications(sort: { field: RUNTIME_VERSION, order: ASC }) {
      items { id latest { version runtime { version } } }
    }
  }
}
```

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>Runtime</b></code>](/api/graphql/types/objects/runtime.mdx) <Badge class="badge badge--secondary " text="object"/> 
A bundle that applications run on.

A runtime holds the infrastructure-as-code, params, and the dependencies its
infrastructure needs. Its massdriver.yaml lists `runtime` under `provides`.
Applications build on one exact runtime version and add their own
dependencies, resources, environment variables, and secrets.
