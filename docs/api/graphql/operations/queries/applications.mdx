List the applications in your organization's catalog.

The list holds the applications whose bundle repository you can view. Use
`filter.runtimeId` for the applications on one runtime.

```graphql
query {
  applications(organizationId: "your-org-id", filter: { runtimeId: { eq: "lambda" } }) {
    items {
      id
      latest { version runtime { version } }
    }
    cursor { next }
  }
}
```


```graphql
applications(
  organizationId: ID!
  filter: ApplicationsFilter
  sort: ApplicationsSort
  cursor: Cursor
): ApplicationsPage!
```
