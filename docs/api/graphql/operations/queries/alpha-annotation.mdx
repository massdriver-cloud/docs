Alpha: this API can change or be removed at any time, without notice.

Get one of your annotations. Another user's annotation is not found.

You need `project:view` on the annotation's project.

```graphql
query {
  alphaAnnotation(organizationId: "my-org", id: "4f6e2a3c-8d1b-4c5e-9a7f-1b2c3d4e5f60") {
    kind
    surfaces
    inputs
  }
}
```


```graphql
alphaAnnotation(
  organizationId: ID!
  id: ID!
): AlphaAnnotation
```
