Fetch a single application by name. Returns `null` with a `NOT_FOUND` error
if no application with that name exists or you cannot view its repository.

```graphql
query {
  application(organizationId: "your-org-id", id: "payments-api") {
    id
    runtime { id }
    latest { version runtime { version } }
    instances { items { id deployedVersion } }
  }
}
```


```graphql
application(
  organizationId: ID!
  id: ID!
): Application
```

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>Application</b></code>](/api/graphql/types/objects/application.mdx) <Badge class="badge badge--secondary " text="object"/> 
A bundle that runs on a runtime.

An application adds its own dependencies, resources, environment variables,
and secrets to a runtime. Its massdriver.yaml sets `app.runtime`, and each
published version is built on one exact runtime version.
