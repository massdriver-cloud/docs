List OCI repositories in your organization's bundle catalog.

Returns a paginated list of repositories of every artifact type (bundles
and resource types). Each repository is the container for all published
versions of its artifact. Use `filter` to narrow by name, artifact type,
or full-text search.

The list holds every repository you can see:

- repositories your `repo:view` group policies match, **plus**
- bundle repositories granted to a project you can view.

A grant to one of your projects adds its repository to the list even when
no `repo:view` policy matches it, and a deny `repo:view` policy does not
remove it. Without `projectId`, grants to every project you can view count.
With `projectId`, only grants to that project count. Each item's `access`
field tells you which rule applies.

```graphql
query {
  ociRepos(organizationId: "your-org-id", filter: { name: { startsWith: "aws-" } }) {
    items {
      id
      name
      tags(sort: { field: VERSION, order: DESC }) {
        items { tag }
      }
    }
    cursor { next }
  }
}
```

List the bundles available in one project, granted bundles first:

```graphql
query {
  ociRepos(
    organizationId: "your-org-id"
    projectId: "ecomm"
    filter: { artifactType: "application/vnd.massdriver.bundle.v1+json" }
    sort: { field: ACCESS, order: ASC }
  ) {
    items {
      name
      access(projectId: "ecomm")
    }
  }
}
```
