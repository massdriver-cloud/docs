Alpha: this API can change or be removed at any time, without notice.

List your annotations in a project, oldest first. Other users' annotations are not returned.

You need `project:view` on the project. Service accounts cannot have annotations.

```graphql
query {
  alphaAnnotations(
    organizationId: "my-org"
    filter: { projectId: "ecomm", entity: { instance: "ecomm-prod-database" } }
  ) {
    items {
      id
      kind
      surfaces
      template
      entity { ... on Instance { id } }
    }
    cursor { next }
  }
}
```


```graphql
alphaAnnotations(
  organizationId: ID!
  filter: AlphaAnnotationsFilter!
  cursor: Cursor
): AlphaAnnotationsPage
```
