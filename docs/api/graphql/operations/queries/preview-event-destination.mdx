List the organization's recent audit log events that a filter matches, newest first. Use it to check a
filter before you create or change a destination with it.

```graphql
query {
  previewEventDestination(organizationId: "my-org", filter: { types: ["deployment.*"] }) {
    items {
      id
      type
      occurredAt
    }
  }
}
```
