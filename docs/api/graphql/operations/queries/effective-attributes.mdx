Returns the attribute keys that apply to an entity type: the `md-*` system keys
Massdriver sets on it and the custom attributes it inherits. For example, scope
`INSTANCE` returns `md-project`, `md-environment`, `md-component`, `md-instance`
and more, plus every custom attribute declared at `PROJECT`, `ENVIRONMENT` or
`COMPONENT` scope.

System keys come first, then custom keys sorted by key. Values are not included;
they depend on the individual entity.


```graphql
effectiveAttributes(
  organizationId: ID!
  scope: EffectiveAttributeScope!
): [EffectiveAttribute!]!
```
