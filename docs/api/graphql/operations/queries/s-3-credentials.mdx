Get AWS credentials for the Massdriver S3 API.

Only requests authenticated with an access token can call this query. The credentials
belong to that access token.

**Example:**

```graphql
query {
  s3Credentials(organizationId: "my-org") {
    accessKeyId
    secretAccessKey
    endpointUrl
  }
}
```


```graphql
s3Credentials(
  organizationId: ID!
): S3Credentials!
```

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>S3Credentials</b></code>](/api/graphql/types/objects/s3-credentials.mdx) <Badge class="badge badge--secondary " text="object"/> 
AWS credentials for the Massdriver S3 API.

S3 tools such as the AWS CLI, the AWS SDKs, and rclone sign requests with these credentials.
They belong to the access token that requested them: they work only in its organization,
and they stop working when the access token expires or is revoked.
