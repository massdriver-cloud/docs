A working Massdriver organization has four parts:

| Part | Where it comes from | What it gives you |
|---|---|---|
| A catalog | [AWS catalog](https://github.com/massdriver-catalogs/aws), or the [pets catalog](https://github.com/massdriver-cloud/massdriver-catalog) | Credentials, resource types and bundles, published from a Git repository you own |
| The official resource types | [massdriver-resource-types](https://github.com/massdriver-cloud/massdriver-resource-types) | Service accounts, Kubernetes clusters and WireGuard tunnels as resources bundles can depend on |
| A platform | Deployed from the catalog (greenfield), or imported from the Terraform you already run (brownfield) | A network, DNS and a place to run containers, set as environment defaults |
| Automations | [massdriver-automations](https://github.com/massdriver-cloud/massdriver-automations) | Services that act on Massdriver events: pull request sync, drift checks, change freezes, auto-deploys |
